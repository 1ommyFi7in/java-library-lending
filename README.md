## Результат этапа

| Что собрать | Что отработать |
| --- | --- |
| Консоль, схема классов, тестовые выдачи и локальный бинарный снимок. | Инварианты модели, полиморфные уведомления, чтение снимка. |

## Как выглядит результат

```text
> lend c1 r1
OK loan c1 r1
> lend c1 r2
ERROR COPY_ALREADY_LENT
> return c1
OK returned c1
> lend c1 r2
OK loan c1 r2
```

## Проверка перед сдачей

- [ ] Проверить пример, независимую выдачу второго экземпляра и отказ на четвёртой активной выдаче.
- [ ] После перезапуска и загрузки экземпляр с активной выдачей остаётся занят. При отказе подменённый отправитель не получает сообщений.
